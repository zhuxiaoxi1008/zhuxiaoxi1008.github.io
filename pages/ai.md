## 搜索技巧

### 常用搜索修饰符

| 修饰符 | 说明 | 示例 |
|--------|------|------|
| `language:` | 按语言筛选 | `language:python` |
| `topic:` | 按话题筛选 | `topic:machine-learning` |
| `stars:>n` | 星数大于 n | `stars:>10000` |
| `stars:n..m` | 星数范围 | `stars:5000..10000` |
| `sort:stars` | 按星数排序 | `python sort:stars` |
| `sort:updated` | 按更新排序 | `react sort:updated` |
| `license:` | 按许可证筛选 | `license:mit` |
| `is:featured` | 特色话题 | `is:featured python` |
| `is:curated` | 精选话题 | `is:curated react` |
| `repositories:>n` | 话题仓库数 | `repositories:>5000` |

### 实用搜索链接

```
# 高星 Python 项目
https://github.com/search?q=language:python+stars:>10000&sort=stars

# 最近更新的 JS 项目
https://github.com/search?q=language:javascript&sort=updated&order=desc

# 精选机器学习话题
https://github.com/search?q=is:curated+machine-learning&type=Topics

# 本月热门
https://github.com/trending?since=monthly

# MIT 许可证开源项目
https://github.com/search?q=license:mit+stars:>1000&sort=stars
```

### Trending 时间筛选

```
https://github.com/trending/python?since=weekly

?since=daily    # 24小时
?since=weekly   # 7天
?since=monthly  # 30天
```

## 快速上手

| 身份 | 推荐路径 |
|------|----------|
| 新手 | Explore -> Star -> Follow |
| 开发者 | Search + Topics -> Dashboard |
| 研究员 | Advanced Search + Custom Filters |

### 发现项目流程

1. **浏览** -> Explore / Trending 了解热门项目
2. **筛选** -> 按语言、话题、星数过滤
3. **评估** -> 看 README、提交历史、Issues 活跃度
4. **收藏** -> Star / Watch / Follow
5. **参与** -> 贡献代码、参与讨论
